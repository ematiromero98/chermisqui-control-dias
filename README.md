# Chermisqui — Control de Días

Demo interactiva (una sola página HTML, sin backend) de un **control de vacaciones
y licencias del equipo** para presentar en Chermisqui.

**Ver la demo:** https://ematiromero98.github.io/chermisqui-control-dias/

Incluye, con datos de ejemplo:
- **Dashboard del manager**: vista Año (línea de tiempo), Mes, Por persona y Análisis (KPIs).
- **Solicitud + aprobación**: las cargas entran como pendientes y se aprueban/rechazan.
- **Alertas de solapamiento** cuando dos personas de la misma área se ausentan a la vez.
- **Formulario del empleado** (mockup de celular): al elegir el nombre trae su saldo y fechas.

Es un demo autónomo: todos los datos viven en el navegador, no toca ninguna base real.
Proyecto **independiente** del ERP interno (repo `calendario-ausencias`).
